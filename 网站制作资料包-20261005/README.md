# 个人网站制作资料包

整理日期：2026-10-05。仅整理现有经历、案例与图片，未制作或发布网站。

## 推荐阅读顺序

1. [个人介绍与能力文案](01_个人介绍与能力文案.md)：简介、性格、能力表达及留空字段。
2. [全部项目目录](02_全部项目目录.md)：38条记录，进入各案例卡查看内容、角色、成果、边界、图片和来源。
3. [成果与完成状态](03_成果与完成状态.md)：5项本人确认参与的付费客户项目、12项优先候选及完成数量未知的口径。
4. [图片选用指南](04_图片选用指南.md)：逐图预览、分类、说明与公开限制。
5. [来源与覆盖说明](05_来源与覆盖说明.md)：核对范围、未检查范围和缺图项。
6. [给网站制作会话的交接说明](给网站制作会话的交接说明.md)：可直接发送给后续制作会话。

## 可复用数据

- 项目内容资料库.json / 项目内容总表.csv：38条结构化案例。
- 精选图片登记.json / 精选图片登记.csv：23项，22张目视核对及1项解码失败；来源、尺寸、哈希与选用建议。
- 图片/：原尺寸精选原图，未重绘、修图或裁切。
- 图片与媒体候选索引.json：约2万条原路径候选，非逐张审查，也非全部原创或可公开素材。

“推荐候选”不等于获得公开许可。整包先内部交接，公开网站只使用最终核准的文案和素材。
