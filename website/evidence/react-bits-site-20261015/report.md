## 范围与边界

用户指定 Circular Carousel，随后扩大为使用 React Bits 全面升级网站。本轮由当前网站会话执行，覆盖首页、关于、项目库、38 份案例的中英文模板及共用导航/页脚样式。保留静态生成结构、业务文案、项目事实、案例次序、原始图片、Pattern Waves 四段着色器、搜索/筛选/返回来源与截图查看器。仅本地，无服务器连接、部署或索引开放。

## 发现并修复

- 短滚轮原来可能吸附回当前图片，现沿滚动方向完成切换。
- 快速导航期间整页快照可能挡住首击。头部提前注册首页及非共享导航取消，整页捕获关闭，保留案例标题共享过渡；所有过渡装饰不接收指针。
- 首页入口的磁吸和入场位移改到内部装饰，真实链接保持静止。
- 动态偏好变更时，背景已停而按钮状态可能暂时滞后；渲染帧退出前同步控制状态。
- 减少动态/无增强回退保留原有图片入口，隐藏环形展示专用的重复放大链接。
