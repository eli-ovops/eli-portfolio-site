# 客户搜索落地视角：第一性原理与对抗式审查

2026-10-14；线上版本05f7213ef85c4cd8a350 / 20261014-110604-return-origin。只读，无源代码、站点配置、服务器或索引变更；新增本目录报告、DOM读数及截图。

判断：视觉有辨识度，陌生客户决策链仍不完整。核心问题是需求匹配、可核验证据、合作下一步，而不是继续加特效。

第一性原理：搜索访客带着具体业务问题，进入任意案例后需要判断 ①是否对应问题 ②哪些能力已被证明 ③本人负责什么且能交付到哪一步 ④如何开始合作。搜索主题为评审候选场景，非真实SERP、搜索量或询盘数据。

## 优先问题

1. P1 接案边界及初次合作流程不明确。首页是业务系统/AI工作流与FDE介绍，关于问答分别讲独立或团队、看成果、联系前准备什么。未给接案类型、交付物、估算周期依据、维护/移交边界。客户不知道是否适合找本人。最小建议：用一段简短合作范围加2-3个业务入口，先写确认过的事实；报价按哪些因素估算可以说明，未确认价格/周期/回复承诺不编。
2. P1 核心证据不足以等同商业效果。P10已交付未全面使用，P09历史虚拟库存现场待核，P36本人说明+初始界面且真实问答/检索记录缺失。RAG示意明确标AI生成，标注值得保留，不能拿它替代工程证据。P07仅背景、职责、功能，没有方法、状态、验收和询盘链路展示。最小建议：优先补已授权真实记录及脱敏操作图/回放；没有资料的只保持阶段说明。P10一项复查发现问题未交代问题类型及后续状态，有有效资料时再补。
3. P1 案例末尾缺明确合作下一步。P10/P09/P36/P07主内容以关联或更多项目结束，通用footer仅邮箱/电话及社媒；微信在关于页。首页联系我实测可到contact（top141px，y2770）。不是没有联系渠道，是在读完对应案例的决策时刻需要自己寻找。最小建议：加一行有类似需求、说明流程与目标、讨论范围的入口到现有联系区，不加复杂表单/未授权发送。
4. P2 搜索意图未形成清楚业务入口。当前主页概括四类能力，P07 title某家具品牌官网案例，详细页主要介绍过去经历；缺客户适用场景、交付边界、下一步的短入口。保留作品集，基于真实案例先补库存/扫码或企业官网两个主题的客户阅读路径，不自动建大量SEO页面、不泛化成完整ERP或保证获客。
5. P2 内部搜索按项目库存组织，客户业务词匹配较弱。实测进销存0、库存2、网站9；网站结果含库存/扫码/产品目录/原型（网站与工具分类）。不是断言没有能力，而是相关性和词汇距离。最小建议：按客户目标给快捷入口，补真实适用的同义词/提示；进销存可引向相关库存案例并说明不等于全套功能。
6. P2 示意和可运行证据在首页排序中不够直观。首页RAG第2但可公开问答是AI示意；用户必须点入才能看到完整证据限制。最小建议：卡片加入一条简短阶段信息，按业务主题选择相关案例；全库38记录保留，不按数量证明交付。不要删除坦诚的限制来改善转化。

## 保留

HELLO/I'M ELI、深色蓝紫、3D画廊与既有动画；P10/P09的具体库存表及阶段边界；双语/作者/普通链接/页面canonical/真实DOM JSON-LD；常见问题可展开和现有联系入口。技术元数据不是本轮发现的主要短板。

## 最小下一轮

先在一个库存案例上验证完整决策链：明确适用流程和范围→已有真实证据→相似需求联系入口。再用同样结构补其他强案例。不是把所有页面继续写长。找未参与项目的客户走入口→案例→联系，能正确复述适用需求、证据阶段和下一步作为阅读验收。没有实际用户测试，不给转化率或排名提升保证。

## 验证与限制

实际查看首页、关于、项目库及P10/P09/P36/P07；7页与robots公网SHA匹配发布包。真实IAB桌面截图、正文/元数据/JSON-LD、问答展开和客户搜索三词；390px P07/about DOM无整页横向溢出，模拟已恢复。手机截图接口将390px内容缩于物理画布，仅作局限记录，不能证明实体手机观感。未测试真实触屏、二维码识别/送达、全部38案例、英文全库、FPS/Core Web Vitals/竞品排名/百度Google真实自然流量。

快速批量导航一次未离开P09，隔步确认后普通关于导航通过，原因UNKNOWN；猜错FAQ role/data-nav定位仅工具no_matches，不能算网站缺陷。直接锚点reload先未到contact，随后真实首页联系按钮到contact，不能据前者说联系入口失效。pages.json的about条目实际仍是P09，应排除，about-confirmed才是关于证据。

Google有用内容指导强调明确受众、亲历证据和让访客完成目标，不设固定字数。Google AI搜索不要求额外特殊schema/AI文本文件；不把这些Google规则扩称百度/Bing专有规则。Jina中介一次401无重试；官方公开页通过web工具已读。当前noindex,nofollow符合用户要求，非误配置，不开放收录。
