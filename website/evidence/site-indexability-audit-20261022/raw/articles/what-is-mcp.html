MCP 是什么？为什么叫连接 AI 的接口？

MCP 是让 AI 应用与外部数据、工具交互的一种开放协议。

文章目录

先弄明白

可以把它理解成共同约定的连接方式，而不是万能权限钥匙。是否支持某个服务，还取决于客户端、服务器与授权。

分三步试一试

  • 选一个只读资料查询需求。
  • 查客户端是否支持对应 MCP 服务。
  • 确认提供哪些工具和数据访问范围。

可以这样问

先准备好

只画连接关系，不要求安装服务器。这里的“服务器”指提供工具的程序，不一定是单独购买的机器。

练习材料（虚构示例）

场景：AI 应用通过 MCP 服务读取练习手册。请标明应用、工具服务、手册，以及授权发生在哪里。

把提示词里的占位符换成上面的材料；没有占位符时，将材料接到提示词后。阅读时长不含实际练习。

用“客户端、MCP 服务、数据源”画出查询链路，指出每一处是谁授权，不实际连接账号。

结果怎么核对（供练习对照）

应区分三方；MCP 不会自动附带手册，也不会自动获得所有文件权限。

遇到问题怎么办

只装上服务却查不到数据时，检查账号范围和工具返回，不认为协议自动带数据。

怎么判断学会了

你能说明请求经过哪几方，哪里可能缺权限。
