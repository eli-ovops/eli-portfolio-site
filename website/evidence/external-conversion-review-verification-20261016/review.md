# 外部咨询转化报告复核

复核日期：2026-10-16。线上版本4214c0d6f6cd8e3dd8ce。本轮只读核对报告与当前官网，并记录结论；没有修改网站。重复观点只合并为一个假设，不把报告数量当真实客户验证。

## 可以采纳的方向

1. 首次咨询附近需要说明先说什么、接下来如何判断、何时另行报价。页面并非完全没有这些内容，已有FAQ及服务页说明；问题是分散和不够贴近联系动作。优先搬移或替换已有文字，不叠加长段落。
2. 500元起有真实对应范围的业务定义缺口。免费沟通与收费实施已有区分，不能称全站未说明；但最小收费范围仍不明确。不能由模型发明单次、每天、20至30分钟、报告或工具订阅等承诺。
3. 30+成功案例的公开统计口径需要能追溯。当前项目库38条、客户项目筛选9条已实测，但9条不等于9个独立客户，也不能由此证明30+虚假。用户曾确认该表述，修改前需明确口径。研究原型应继续与客户交付区分。
4. 案例可以增加原来的工作问题、实际交付的功能、当前有证据支持的状态等业务摘要。没有真实使用数据和客户原话，不写60%/80%、明显提升或客户满意等看似温和但仍是事实断言的内容。
5. 文字版微信号及首条消息范例可降低操作成本。微信号是否公开、回复时间和免费诊断方式由本人确认。不能把个人手机号擅自当微信号，不承诺24小时回复或30分钟咨询。

## 不宜直接执行

- 不把FDE/AI Agent从所有title、URL和服务内容中删除：用户已有这类关键词定位需求。可以先用业务语言解释，术语保留在身份或细节位置，不承诺排名变化。
- 不把所有折叠内容默认展开：这与用户减少正文、保持紧凑的明确要求冲突。只把首访必需的一句话露出。
- 不因“首屏短暂空白”就删除动效：入场过程与持续不可读须区分，需要真实时序证据。
- 不为信任强制公开真名、本人照片、私人地址；可先提供本人确认的常用称呼、经历与合作方式。
- 不用未经确认的客户效果、时长、回复时限或收费套餐填空。

## 建议最小修改包

1. 先补或前移联系区的第一步引导；保持现有视觉，不加浮窗和长文章。
2. 待本人确认后统一500起步范围、30+统计口径、免费初诊形式与可公开微信号。
3. 为2至3个成熟案例写业务摘要；P12可保留于项目库，商业首页是否继续主推单独决策，不删除资产或改成已成功。
