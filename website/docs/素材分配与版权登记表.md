# 素材分配与版权登记表

> 适用范围：贯穿 P1-P3，并在 P6 测试、P9 审计和 P17 性能 / 可访问性检查中复核。
> 硬规则：来源不等于授权；“客户提供”“公开网络”“AI 生成”都不自动等于可商用。AI 只能盘点、分类和建议，不能代替人工确认版权、人物隐私、最终用途或发布批准。

## 1. 编号与状态规则

- 素材编号使用 `MAT-NNN`；同一原始素材跨页面复用时保持素材编号不变。
- 每个页面落位使用独立分配编号 `ALLOC-NNN`，并关联 `SLOT-P3-NNN`。
- 来源类型只能使用：`客户提供 / 自有拍摄 / 授权图库 / 第三方提供 / AI 生成 / 公开网络 / 其他 / 待确认`。
- 版权授权状态只能使用：`待确认 / 已授权 / 许可范围不足 / 未授权 / 不适用`。
- 人物 / 隐私状态只能使用：`不涉及 / 待确认 / 已获授权 / 需脱敏 / 禁止使用`。
- 流水线状态按下列值流转：
  `待盘点 -> AI 已建议 -> 待人工确认 -> 已确认待处理 -> 已处理待映射 -> 已映射待测试 -> 测试 / 审计通过`。
- 异常状态使用：`需补授权 / 需处理隐私 / 需替换 / 不采用 / 已回滚`。
- AI 最多推进到 `AI 已建议`，不得自行推进到任何人工确认、可用或通过状态。

## 2. 素材流水线

```text
素材收件箱
-> AI 盘点和建议分类
-> 生成素材分配与版权登记表
-> 人工确认用途 / 版权 / 人物与隐私
-> 压缩、裁切、格式和 alt 处理
-> 映射到页面骨架占位
-> P6 测试、P9 审计、P17 性能与可访问性复核
```

### 发布硬门禁

- 版权不是 `已授权` 或经具名人工确认的 `不适用`，不得发布。
- 人物 / 隐私不是安全状态，或脱敏未复核，不得发布。
- AI 建议、公开网络来源、客户提供或 AI 生成均不能替代授权证据。
- 未记录最终路径、页面映射、alt、测试证据和替换 / 回滚说明，不得标为 `测试 / 审计通过`。
- AI 不得未经人工确认批量分配、替换、发布或下线素材。
