### 通过标准

- 每个拟保留或调整的元素均完成“参考元素 -> 项目目标 / 用户 / 页面 -> 保留 / 调整 / 拒绝”映射。
- 拟采用项均有原创化方案，并评估版权、性能与可访问性影响。
- 参考来源和采集依据可追踪；来源或授权不明的素材只可内部研究，不得进入页面发布。
- 本表不替代竞品拆解、页面架构和本项目既有的 P1 通过标准。

### 退回条件

- 出现复制源码、Logo、商标、图片、字体文件、视频、图标、品牌资产或整段文案的计划，直接退回。
- 处理决策缺少项目目标、目标用户、页面映射或原创化方案，退回补充。
- 版权、性能或可访问性高风险未处理，不得进入正式设计；只能保留为内部研究或拒绝。
