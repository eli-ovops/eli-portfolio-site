## 技术选择

当前网站由Python标准库生成静态HTML，原有app.js负责导航和项目库。比较了原生CSS／WAAPI、[GSAP](https://gsap.com/docs/v3/GSAP/)及React Bits组件方案：本轮运动不涉及复杂时间轴、物理仿真或WebGL，采用独立motion.js与motion.css最符合当前结构。没有引入React、GSAP、motion、外部脚本或新的npm依赖，也没有复制第三方组件代码、字体或媒体。

所有动效为本站原生实现，参考的是运动方式。标题与图片只入场一次；卡片倾斜和磁吸由真实指针事件触发，读写通过requestAnimationFrame合并，没有持续空跑的动画循环。卡片使用稳定父元素的矩形，避免变换后测量造成倾斜抖动。图像提示限制在图片内，且不遮挡点击事件。

## 运动参数与用途

| 元素 | 时间或范围 | 目的 |
| --- | --- | --- |
| 开场／案例标题 | 740ms，行间90ms；translateY 105%至0 | 让一句介绍有明确入场节奏 |
| 项目截图 | 780ms，两张错开85ms；遮罩与34px位移 | 把视线引向可展示产出 |
| 文字案例行 | 560ms，22px位移 | 随阅读自然出现 |
| 截图倾斜／提示 | X≤4°、Y≤5°；提示88px | 明确图像可进入案例 |
| 入口磁吸 | X≤8px、Y≤6px；360ms归位 | 细微的指针反馈 |
| 案例标题滚动／跨页揭开 | 440ms | 让浏览和进入案例保持连续感 |
| 肖像 | 旋转≤2°、滚动位移≤18px | 少量个人感，保留可替换标记 |

主要入场使用缓动cubic-bezier(0.16,1,0.3,1)。跨页只揭开新快照，旧快照不透明，避免整页交叉淡入的文字重影。原生链接没有被拦截，没有滚动锁定或锚点等待。

## 可用性与证据边界

正文在源HTML中默认可见，脚本只增强表现；不支持WAAPI、IntersectionObserver或View Transition时回退原生内容和导航。装饰元素不进入可访问名称；标题克隆aria-hidden，链接仍只有一个可访问名称，原有焦点和44px导航目标保留。

触屏关闭指针专属效果，减少动态偏好取消入场、倾斜、磁吸、肖像变化、标题滚动、阅读进度和跨页动画。当前浏览器实际验证了上述偏好、触屏模拟、倾斜矩阵、磁吸位移和活动转场遮罩，不以静态截图或编译成功替代动效证据。

浏览器自动化未暴露document.getAnimations，raw CDP的Animation.enable不受支持；使用受支持的只读getComputedStyle与原生指针输入验证。关闭脚本也会阻止自动化定位器的Runtime.evaluate，恢复后结束该额外检查。完整无JS浏览器路径未验收。实际手机、跨浏览器、帧率、用户审美认可及公开发布未验收。
