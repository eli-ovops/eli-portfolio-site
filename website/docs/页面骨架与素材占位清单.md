## 1. 状态与编号规则

- 骨架项编号使用 `SLOT-P3-NNN`，关联 `REQ-P0-NNN` 与 `VIS-P1-NNN`。

- 阶段门禁结论只能使用：`通过 / 条件通过 / 退回`。
- AI 生成的骨架默认为 `草案` 或 `待确认`；不得把假登录、假上传、假导出、假提交、假搜索写成真实能力。

### 通过标准

- 一期每个路由和模块都有用户目标、内容字段、组件 / 交互、验收标准和确认状态。
- 加载、空、错误、404 / 兜底状态已定义；桌面和移动端要求明确。
- 所有图片 / 视频占位均有唯一 ID、类型、比例和尺寸，并可关联素材登记。
- Mock / 真实边界逐功能落表，不只写在总说明中。
- P3 仍需构建、页面可访问、控制台和演示证据才能按原 SOP 通过；本表确认不能推导 L1/L2 完成。

### 退回条件

- 范围漂移退回 P2；视觉映射冲突退回 P1；关键业务事实不清退回 P0。
- 版权、人物隐私或最终用途未确认的素材，退回素材流水线并保持占位，禁止发布。
- 假登录、假导出、假上传、假提交或假搜索被描述为真实能力，直接退回整改。
